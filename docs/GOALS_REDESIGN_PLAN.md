# План: страница «Цели»

## Концепция: Rolling Wave + ИИ-ассистент

Каскадное планирование от мечты до недельных задач. Ближнее — детально, дальнее — крупно. ИИ помогает декомпозировать мечту через диалог.

---

## Пользовательские сценарии

### Состояние 0 — Пустая страница

Пользователь видит только поле «Напиши свою мечту» и кнопку сохранения. Больше ничего на странице нет.

### Состояние 1 — Мечта без горизонта

Мечта сохранена, но горизонт не задан. На странице:

- Мечта (текст)
- Предложение: «Задай горизонт сам» (выбор лет) или «Обсуди с ИИ» (кнопка)
- Карты планирования нет — она появится после определения горизонта

### Состояние 2 — Мечта + горизонт → карта планирования

Горизонт задан (самим или через ИИ). Появляется полная карта:

- Мечта (компактная полоска + прогресс)
- Карточки целей по годам
- Шкала 12 месяцев выбранного года
- Детализация выбранного месяца + недели

### Три сценария заполнения карты

#### Сценарий А — Сразу вызвать ИИ

1. Пользователь сохранил мечту (только текст)
2. Нажимает «ИИ Помощник»
3. ИИ помогает определить горизонт, уточняет детали
4. ИИ предлагает декомпозицию: годы → кварталы → ближайший месяц → недели
5. Пользователь нажимает «Принять план» → горизонт задаётся, карта заполняется
6. Панель закрывается, пользователь видит готовую карту

#### Сценарий Б — Самостоятельное заполнение

1. Пользователь сохранил мечту, сам задал горизонт
2. Система показывает карту планирования
3. Пользователь заполняет сверху вниз: цели года → месяца → недели
4. ИИ не участвует

#### Сценарий В — ИИ на любой стадии

1. Пользователь частично заполнил карту
2. Нажимает «ИИ Помощник»
3. ИИ видит контекст: мечта + всё заполненное + выбранный период
4. Помогает точечно: «Q2 пустой. Давай декомпозируем?»
5. Пользователь принимает → задачи добавляются в карту

### Правила отображения

| Состояние | Что видно |
| ----------- | ----------- |
| Нет мечты | Только поле ввода мечты |
| Мечта без горизонта | Мечта + выбор горизонта / кнопка ИИ |
| Мечта + горизонт | Мечта + полная карта планирования |
| Любое состояние | Вертикальная кнопка ИИ справа |

## Конструкция страницы

```text
┌─ Мечта (компактная полоска + прогресс) ───────────────────────────────┐
├─ Карточки целей по годам (горизонтально, скролл) ─────────────────────┤
├─ Шкала 12 месяцев выбранного года (sticky) ──────────────────────────┤
├─ Детализация выбранного месяца ──────────────────────────────────┬───┤
│  Цели месяца                                                    │ И │
│  W1 · W2 · [W3●] · W4                                           │ И │
│                                                                  │   │
│  W3 · 9–15 марта                                                │ П │
│  ☐ Задача 1  🔴  #тег                                          │ О │
│  ☑ Задача 2  ✓                                                  │ М │
│  + добавить                                                      │ О │
│                                                                  │ Щ │
│                                                                  │ Н │
│                                                                  │ И │
│                                                                  │ К │
└──────────────────────────────────────────────────────────────────┴───┘
                                                                   ↑
                                                          вертикальная
                                                          кнопка-сайдбар

При клике на кнопку → выезжает панель диалога:

┌─ Карта целей ─────────────────────────┬─ 💬 ИИ-помощник ────────────┐
│                                       │  Контекст: Март 2026        │
│  (сжимается, уступая место)          │                              │
│                                       │  ИИ: Давай разобьём цели    │
│                                       │  на недели марта...          │
│                                       │                              │
│                                       │  > Мой вопрос               │
│                                       │  [Отправить]                │
│                                       │                              │
│                                       │  [✕ Закрыть]               │
└───────────────────────────────────────┴─────────────────────────────┘
```

### Поведение ИИ-панели

- По умолчанию скрыта — вертикальная кнопка «ИИ Помощник» справа
- Клик → панель выезжает справа (slide-in), карта сжимается
- Закрыть → панель уезжает, карта получает 100% ширины
- На мобильном — панель открывается как bottom sheet

## Этапы реализации

### Этап 1 — Страница и компоненты

- [x] **1.1** Компонент `DreamBar` — компактная мечта: одна строка (текст + прогресс-бар), раскрывается по клику для редактирования
- [x] **1.2** Компонент `StrategyCards` — горизонтальные карточки по годам. Каждый год = карточка с целями и прогрессом. Клик переключает шкалу месяцев. Внутри: цели года + квартальные цели (свёрнуты, раскрываются по клику)
- [x] **1.3** Компонент `MonthTimeline` — 12 месяцев горизонтально, текущий выделен, клик = детализация ниже
- [x] **1.4** Компонент `MonthDetail` — детализация выбранного месяца: цели месяца + полоска недель + карточка выбранной недели с задачами (используется MonthSection)
- [x] **1.5** Компонент `WeekCard` — карточка недели: задачи с чекбоксами, приоритетами, тегами, drag-and-drop (существующий)
- [x] **1.6** Sticky-навигация — шкала месяцев прилипает при скролле
- [x] **1.7** Мобильная адаптация
- [x] **1.8** Страница `page.tsx` — три состояния (пусто / мечта без горизонта / карта), собирает компоненты

### Этап 2 — ИИ-панель (выезжающий сайдбар)

- [x] **2.1** Компонент `GoalsChatTrigger` — вертикальная кнопка справа, всегда видна
- [x] **2.2** Компонент `GoalsChatPanel` — выезжающая панель (slide-in справа), карта сжимается, кнопка ✕ закрывает
- [x] **2.3** Хук `useGoalsChat` — сообщения, отправка, стрим, контекст выбранного периода
- [x] **2.4** API `/api/goals/decompose` — контекст (мечта, цели, период) → стрим от Anthropic
- [x] **2.5** Промпт для декомпозиции — помочь разбить мечту на годы → кварталы → месяцы → недели
- [x] **2.6** Контекстная привязка — клик на элемент карты переключает контекст ИИ-панели
- [x] **2.7** Кнопка «Принять план» — ИИ предлагает задачи, пользователь подтверждает → добавляются в период
- [x] **2.8** Мобильная версия — bottom sheet вместо slide-in

### Этап 3 — Режимы ИИ

- [x] **3.1** Первый запуск — ИИ через вопросы строит каскад (горизонт → годы → ближайший месяц → недели)
- [x] **3.2** Детализация волны — при приближении нового месяца: «Наступает апрель. Давай разобьём на недели?»
- [x] **3.3** Свободный вопрос — «Я не успеваю, что перенести?»
