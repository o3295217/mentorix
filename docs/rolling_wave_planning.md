# Rolling Wave Planning — алгоритм для ИИ-планировщика

## Концепция

Пользователь формулирует мечту. Горизонт планирования определяется в диалоге или задаётся пользователем явно — от 1 месяца до 10 лет и более.

План строится волной: текущий месяц всегда детализирован до недель, всё что дальше — укрупняется по мере удалённости. По мере движения времени волна накатывает на следующий период — он раскрывается на уровень ниже, вплоть до недель.

---

## Правило детализации

| Период | Детализация |
|---|---|
| Текущий месяц | По неделям |
| Следующие месяцы | По месяцам |
| Следующие кварталы | По кварталам |
| Следующие полугодия | По полугодиям |
| Следующие годы | По годам |

Уровни применяются только те, которые нужны для конкретного горизонта.

**Правило количества блоков на уровне:** на каждом уровне детализации отображается столько блоков, сколько остаётся до конца объемлющего периода следующего уровня. Текущий квартал раскладывается на месяцы (до 3), оставшиеся кварталы текущего года показываются поквартально (до 3), полугодия следующего года — по полугодиям (до 2), далее — по годам.

**Правило неполного блока:** последний блок на любом уровне может покрывать меньше стандартного периода. Например, квартальный блок может содержать 1–2 месяца, полугодовой — 1–2 квартала. Укрупнение только нарастает, никогда не откатывается на более мелкий уровень. Цели ставятся на блок как единое целое, независимо от его фактической длительности.

---

## Алгоритм накатывания волны

Когда заканчивается текущий месяц — первый из следующих месяцев разбивается по неделям, становится текущим. Освободившееся место пополняется: следующий по иерархии существующий блок (квартальный, полугодовой или годовой) отдаёт один месяц.

Когда заканчивается текущий квартал (все месяцы израсходованы) — первый блок следующего существующего уровня раскрывается на уровень ниже. Если в плане есть квартальные блоки — первый квартал разбивается на месяцы. Если квартальных блоков нет, но есть полугодовой — он разбивается на кварталы, первый из которых сразу раскрывается на месяцы. Первый месяц всегда разбивается по неделям. Каскад идёт сверху вниз до недель.

Аналогично при смене полугодия и года — каждый раз раскрывается первый блок следующего существующего уровня, и волна спускается вниз по цепочке до недель.

**Правило пополнения:** освободившееся место на любом уровне пополняется от следующего более крупного уровня, если он существует в плане. Если более крупного уровня нет — горизонт сокращается, блок не пополняется.

**Главное правило:** структура плана сохраняет форму волны. Ближайший период всегда детализирован до недель, дальние — укрупнены. Волна сдвигается вперёд, каждый раз раскрывая следующий блок на уровень ниже — до недель.

## Примеры структуры плана

### 3 месяца

```
Текущий месяц  → недели
Месяц 2        → месяц
Месяц 3        → месяц
```

### 6 месяцев

```
Текущий месяц  → недели
Месяц 2        → месяц
Месяц 3        → месяц
Квартал 2      → квартал
```

### 8 месяцев

```
Текущий месяц  → недели
Месяц 2        → месяц
Месяц 3        → месяц
Квартал 2      → квартал
Квартал 3      → квартал (неполный, 2 месяца)
```
